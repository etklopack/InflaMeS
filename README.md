# InflaMeS
## Code used to train InflaMeS in HRS and needed to reproduce InflaMeS in other data.

To create InflaMeS in your data:
Download and unzip the making_inflames.zip folder.
Follow directions in read_me.txt.
The R markdown file replication.Rmd is used to calculate InflaMeS in your data.
